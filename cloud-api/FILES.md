Key plans-only (r8) changes: `internal/payment/catalog.go` — `PlanSKU`
replaces `Pack` (plan_code + period_days, never credits);
`internal/payment/domain.go` — Order carries the plan snapshot +
provider browser handles; `SubscriptionState` replaces `Balance`;
`internal/store/repos/payments.go` — `ApplyPaid` activates/extends the
subscription (extend-or-insert, stacking periods) in the same transaction;
`internal/auth/identity.go` — FREE-PLAN DEFAULT fallback (every tenant is
Free until they buy Pro; expiry returns them there automatically);
`internal/store/migrations/000012_plans_only.sql` — drops the credit
tables, `pack_id`→`sku_id`, adds `plan_code`+`period_days`, drops
`credits`; API surface: `GET /v1/payments/subscription` replaces
`/v1/payments/balance`; `internal/payment/{stripe,phonepe}/` — the second
and third production Providers (wire-compatible fakes in their test
suites; service-level lifecycles in `stripe_e2e_test.go` /
`phonepe_e2e_test.go`); `internal/api/payments_test.go` — the ROUTE-level
scenario matrix through the real router + auth chain;
`docs/FRONTEND-PAYMENTS.md` — the client integration guide (endpoint map,
the PhonePe sequence, subscription view);
`docs/MODELS-AND-PRICING.md` — the launch decision doc (model lineup,
price-proportional normalization, Free/Pro design, Indian-market pricing,
ZDR matrix);
`internal/store/migrations/000011_model_economics.sql` — the launch
model lineup as price-proportional token_normalization rows + Free-plan
model allowlist.
