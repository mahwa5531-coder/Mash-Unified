# Indian Statutory Audit Master Skills Catalog

This directory contains 73 specialized statutory audit skills aligned with ICAI Standards on Auditing (SA 200–700), Companies Act 2013, CARO 2020, Schedule III, and Ind AS / AS frameworks.

## How to Use These Audit Skills
When performing an audit procedure for a specific cycle, inspect the relevant markdown file in the catalog below using `read_file` to review testing objectives, required inputs, substantive steps, ICAI standard references, and working paper templates.
