# Group Audit Considerations

## Purpose
Plan, perform, and conclude group audits involving components, component auditors, and joint audits per SA 600.

## Scope
- USE WHEN: Group with subsidiary / associate / JV / branch in different location / jurisdiction; listed entity with subsidiaries.
- DO NOT USE WHEN: Single entity audit with no components; wholly-owned single-location operations.
- AUDIT AREAS: Component materiality, component auditor scope, group-wide controls, consolidation, reporting.

## Audit Objective
- Assertions: All assertions for group financial statements.
- Framework: SA 600; SA 315; SA 320; Sec 129/139 of Companies Act; Ind AS 110/111/112.

## Workflow Dependencies
- REQUIRES: Risk Assessment, Materiality Determination, Substantive Testing (group level), Consolidation Review.
- FEEDS: Audit Conclusion, Audit Reporting, Sec 143(2) Group Opinion.

## Required Inputs
- Group structure (holding + subsidiaries + associates + JVs + branches).
- Component list with location, materiality, significance, risks.
- Component auditor engagement letters; independence declarations.
- Group reporting package / consolidation working paper.
- Group-wide controls documentation; group instruction letter to component auditor.

## Optional Inputs
- Prior-year group audit working papers; parent company trial balance; FX rates.

## Knowledge
- SA 600.15: Significant component — financial significance to group; individual risk profile.
- SA 600.18: Materiality for component ≤ group materiality; reduce aggregation risk.
- SA 600.19: Component auditor performance evaluated — competence, independence, regulatory environment.
- SA 600.22: Group engagement team involvement — risk assessment work, analytical procedures at group level.
- SA 600.25: If significant component not audited per group materiality → group auditor visits / additional procedures.

## Workflow
1. Determine group structure and components — list all subsidiaries, associates, JVs, branches (domestic / foreign); identify significant components.
2. Determine significance of components — IF component >15% of group revenue / assets / profit → significant; IF specific risk → significant regardless of size.
3. Determine group materiality and component materiality — component ≤ group; allocate considering aggregation risk; IF significant → set specific materiality.
4. Evaluate component auditor — verify independence (Sec 144 / ICAI Code); competence; regulatory environment; IF not acceptable → group auditor performs or uses another component auditor.
5. Issue group instruction letter — specify scope, materiality, significant risks, reporting format, deadlines, KAM, group-wide controls.
6. Perform group-level risk assessment — identify group-wide risks (consolidation, intercompany, FX, transfer pricing, related party, going concern).
7. Test group-wide controls — test consolidation process; intercompany elimination; FX translation; goodwill; NCI.
8. Perform analytical procedures at group level — compare component performance with expectations; investigate variances.
9. Review component auditor work — obtain documentation; review significant judgments, risks, conclusions; IF significant component not audited → perform additional procedures or visit.
10. Consolidation review — verify elimination of intercompany transactions / balances / unrealised profit; FX translation; goodwill; NCI; equity method.
11. Test related party across components (link to Related Party Identification) — verify intra-group transactions eliminated; cross-border RPT identified.
12. Evaluate sufficiency of evidence — aggregate uncorrected misstatements across components; assess against group materiality. Conclude on group opinion; coordinate reporting with component auditor; address any modifications.

## Decision Points
- D1: Component significant (>15% or specific risk)? YES → full scope audit at component materiality. NO → analytical procedures at group level.
- D2: Component auditor independent and competent? YES → rely with instructions. NO → group auditor performs / replaces.
- D3: Component in different regulatory environment? YES → additional review of regulatory compliance. NO → standard review.
- D4: Joint auditors appointed (Sec 139)? YES → divide work; coordinate reporting; joint or separate report. NO → single auditor.
- D5: Branch audit required (Sec 143(8))? YES → branch auditor appointed; report to principal auditor. NO → no branch audit.

## Professional Skepticism Probes
- Are component auditor's risk assessments aligned with group risk profile?
- Are significant judgments at component level challenged by group team?
- Are intercompany transactions genuinely eliminated or selectively?
- Is FX translation applied consistently across components?
- Are foreign component disclosures compliant with Indian reporting framework?

## Considerations
- Component materiality: aggregation risk reduces component materiality below group materiality.
- Significant component threshold: 15% indicative — not mechanical; qualitative factors matter.
- Group instruction letter: specify KAM for listed entities; deadlines.
- Foreign component auditor: evaluate equivalent standards (ISA / national equivalent).
- Branch audit (Sec 143(8)): branch auditor reports to principal auditor who incorporates.

## Common Risks
- Component materiality set equal to group materiality (aggregation risk).
- Significant components not identified (qualitative risk ignored).
- Component auditor not evaluated for independence / competence.
- Group instruction letter vague on scope and reporting.
- Intercompany eliminations incomplete.

## Fraud Triggers (SA 240)
- Intercompany transactions at non-arm's length to shift profits.
- Shell components used to inflate group revenue.
- Component auditor selected based on relationship with management.
- Intra-group receivables unrecoverable but not provided.
- Goodwill impairment avoided by inflated component forecasts.

## Common Pitfalls
- Not allocating component materiality correctly.
- Missing qualitative significant components (high risk, low size).
- Accepting component auditor without independence / competence evaluation.
- Vague group instruction letter.
- Not reviewing component auditor's documentation.

## Validation
- [ ] Group structure mapped; significant components identified.
- [ ] Group and component materiality determined and documented.
- [ ] Component auditor independence and competence evaluated.
- [ ] Group instruction letter issued; component scope defined.
- [ ] Group-wide controls (consolidation, FX, intercompany) tested.

## Expected Outputs
- Group audit strategy and instruction letter.
- Component significance assessment memo; component materiality memo.
- Component auditor evaluation memo (independence, competence, regulatory environment).
- Group-wide controls and consolidation review working paper.

## Failure Conditions
- Component auditor's report / documentation unavailable.
- Significant component not audited and access denied.
- Group instruction letter not acknowledged by component auditor.

## Escalation Conditions
- Significant component unaudited / access denied → STOP, scope limitation, modify opinion (SA 705).
- Component auditor independence compromised (Sec 144) → STOP, replace or perform audit, partner consultation.
- Material intercompany fraud identified → STOP, SA 240, Sec 143(12) reporting.
- Disagreement with joint auditor unresolved on material matter → STOP, partner consultation, possibly separate report with basis.
