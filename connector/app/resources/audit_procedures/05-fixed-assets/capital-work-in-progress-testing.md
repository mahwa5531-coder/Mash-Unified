# Capital Work-in-Progress Testing

## Purpose
Verify CWIP aging, stalled projects, capitalization delays, interest capitalization cessation, cost overruns, advances to suppliers, idle CWIP impairment (Ind AS 36).

## Scope
- USE WHEN: Material CWIP balance; projects in progress; long-aged CWIP.
- DO NOT WHEN: CWIP immaterial; no capex projects.
- AUDIT AREAS: CWIP (tangible), intangible development in progress, advances to suppliers.

## Audit Objective
- Assertions: Existence, completeness, valuation, accuracy, presentation.
- Framework: Ind AS 16, Ind AS 23, Ind AS 36, Ind AS 38, CARO 2020.

## Workflow Dependencies
- REQUIRES: Fixed Assets Additions Testing, Finance Costs Testing, Trial Balance.
- FEEDS: Audit Reporting, Going Concern Assessment, Provisions.

## Required Inputs
- CWIP register with project-wise cost, commencement, expected completion.
- Aging schedule of CWIP.
- Borrowing cost capitalization workings.
- Supplier advance register; reconciliations.
- Project status reports; consultant/engineer certificates.

## Optional Inputs
- Independent progress report; cost overrun board approval.

## Knowledge
- Ind AS 16.22: Self-constructed asset cost includes direct + attributable; transfer to FA when RFU.
- Ind AS 23.20: Capitalize borrowing cost on qualifying asset until RFU.
- Ind AS 23.22: Suspend capitalization during extended delays.
- Ind AS 23.25: Cease capitalization when substantially complete.
- Ind AS 36: Idle CWIP — indicator of impairment; assess recoverable amount.
- CARO 2020 Cl 11: Cost overrun, project delays disclosed.
- Companies Act Sec 143(3): Auditor reports on CWIP if material delay.

## Workflow
1. Obtain CWIP schedule — tie to GL and FS.
2. Prepare aging schedule:
   - <1 yr, 1–2 yr, 2–3 yr, >3 yr.
   - IF CWIP aged >2 yr → assess capitalization delay and impairment indicator.
3. Verify project-wise cost build-up:
   - Vouch sample to invoices, BOQ, contractor bills.
   - IF cost overrun → verify Board approval and rationale.
4. Verify advances to suppliers:
   - IF advance aged long → confirm supplier existence, recoverability.
   - IF supplier not delivering → assess provisioning.
5. Test borrowing cost cessation:
   - IF project substantially complete → cease capitalization.
   - IF substantial delay/suspension → suspend capitalization.
6. Verify stalled projects:
   - IF project stalled >1 yr → assess going concern, impairment (Ind AS 36).
7. Verify RFU assessment:
   - IF project RFU → transfer to FA; if delayed → exception.
8. Verify idle CWIP impairment:
   - IF idle → indicator; compute recoverable amount (VIU/FVLCD).
   - IF impairment → P&L charge.
9. Verify reclassification:
   - IF reclassified from CWIP to expense → verify authorization.
10. Test cut-off — costs in correct period; transfers in correct period.
11. Verify CARO 2020 disclosures: cost overrun, project delays, impairment.
12. Evaluate exceptions — factual/projected/anomalous; project per SA 530.

## Decision Points
- D1: CWIP aged >2 yr? YES → assess delay, impairment indicator. NO → proceed.
- D2: Project stalled? YES → assess going concern, impairment. NO → proceed.
- D3: Borrowing cost capitalization ceased? YES → verify cessation date. NO → exception.
- D4: Supplier advance recoverable? YES → proceed. NO → provision.
- D5: Project RFU but not capitalized? YES → exception, transfer. NO → proceed.
- D6: Cost overrun justified? YES → Board approval. NO → exception.

## Professional Skepticism Probes
- Is CWIP aging genuinely tracked, or selectively aged?
- Is RFU date manipulated to defer depreciation?
- Are cost overruns justified, or concealing mismanagement?
- Are supplier advances genuine, or routed funds?
- Is borrowing cost capitalization properly ceased?
- Are stalled projects assessed for impairment, or carried indefinitely?

## Considerations
- Industry capex cycle: manufacturing vs infrastructure longer lead time.
- Forex exposure on imported CWIP.
- Government grant CWIP (Ind AS 20) — disclosure pending capitalization.
- Legal disputes on land/environment — contingent disclosure (Ind AS 37).

## Common Risks
- CWIP aged indefinitely without capitalization.
- Borrowing cost capitalized post-cessation.
- Supplier advances unrecorded loss or fraud.
- Idle/stalled CWIP not impaired.
- Cost overruns not approved; mismanagement concealed.

## Fraud Triggers (SA 240)
- CWIP aged >3 yr with no progress.
- RFU date repeatedly deferred without justification.
- Cost overruns funded by related-party advances.
- Supplier advances to shell entities.
- Borrowing cost capitalized during suspension.
- Manual JEs to CWIP with vague narration.
- Project completion certificate backdated.

## Common Pitfalls
- Not preparing aging schedule.
- Missing borrowing cost cessation test.
- Accepting supplier advance recoverability without confirmation.
- Skipping impairment assessment on stalled CWIP.
- Not testing cost overrun approvals.

## Expected Outputs
- CWIP testing workpaper with aging.
- Project-wise cost vouching memo.
- Supplier advance confirmation memo.
- Borrowing cost cessation test memo.
- Stalled project assessment.
- Impairment assessment memo (idle CWIP).
- CARO 2020 disclosure checklist.
- Exception summary with projection.
- Conclusion on CWIP per Ind AS 16/23/36.

## Failure Conditions
- CWIP register incomplete; aging not available.
- Project status reports missing.
- Borrowing cost workings unavailable.

## Escalation Conditions
- CWIP aged >3 yr material without justification → STOP, propose adjustment, partner consultation.
- Borrowing cost capitalized post-cessation material → STOP, propose adjustment.
- Stalled project material without impairment → STOP, refer Ind AS 36, escalate.
- Supplier advance to related party without evidence → STOP, fraud risk (SA 240), escalate.
