# Workpaper Documentation

## Purpose
Prepare, organise, and retain audit documentation per SA 230 and Sec 143 of Companies Act.

## Scope
- USE WHEN: Every audit — mandatory documentation throughout engagement.
- DO NOT USE WHEN: Never skip — documentation is mandatory per SA 230.
- AUDIT AREAS: Permanent file, current file, completion, supervisor review, retention, confidentiality, electronic workpapers.

## Audit Objective
- Deliverable: Audit documentation sufficient to enable experienced auditor to understand work performed and conclusions reached.
- Framework: SA 230; SA 580; Sec 143 of Companies Act (8-year retention); ICAI documentation standards.

## Workflow Dependencies
- REQUIRES: All audit procedures and working papers from all skill areas.
- FEEDS: Audit Conclusion, Audit Reporting, Sec 143(1) Filing, Future-Year Reference.

## Required Inputs
- All working papers prepared during audit.
- Permanent file (prior years' papers, contracts, agreements).
- Engagement letter; audit plan; risk assessment; materiality; conclusions.
- Supervisor review notes; sign-offs; management representations.

## Optional Inputs
- ICAI documentation templates; firm methodology manual; prior-year completion memorandum.

## Knowledge
- SA 230.6: Documentation sufficient to enable experienced auditor to understand work performed, evidence obtained, conclusions reached.
- SA 230.8: Document discussions on significant matters with management / TCWG.
- SA 230.14: Assemble audit file on a timely basis — normally not more than 60 days after audit report date.
- SA 230.A7-A11: Form / content / extent — nature of engagement, identified risks, significance of evidence, methodology.
- SA 230.A16: Modifications after assembly — administrative only; substantive modifications documented with reasons.

## Workflow
1. Organise audit file structure — permanent file (contracts, agreements, master data, permanent risk factors); current file (current year risk assessment, working papers, conclusions, report).
2. Document each working paper — header (entity, period, area, prepared by, date); subject; procedure performed; evidence; conclusion; tickmarks (legend); cross-references.
3. Document significant discussions — record discussions with management / TCWG on significant matters (SA 230.8); date, attendees, summary, conclusion.
4. Document professional judgments — capture significant judgments (materiality, risk assessment, going concern, estimates, fraud) with reasoning and evidence.
5. Document exceptions and resolutions — log exceptions, investigation, resolution; if unresolved → escalate and document.
6. Obtain preparer and reviewer sign-off — preparer signs and dates; reviewer signs and dates with review notes.
7. Address supervisor / partner review notes — clear each note; document clearance; if note requires additional procedure → perform and document.
8. Document management representations — file signed representation letter (SA 580); file board resolution authorising signatory.
9. Cross-reference working papers — tie numbers from working papers to trial balance, financial statements, audit report.
10. File audit report and supporting documentation — final report; CARO Annexure; management letter; TCWG communication (SA 260).
11. Assemble audit file — complete file assembly within 60 days of audit report date (SA 230.14); administrative modifications thereafter only.
12. Retain per Sec 143 — 8 financial years — maintain physical / electronic file; ensure accessibility; protect confidentiality. Apply confidentiality — restrict access to engagement team; require authorised disclosure (regulator, court order). Document electronic workpapers — backup; version control; access logs; cybersecurity controls.

## Decision Points
- D1: Documentation sufficient for experienced auditor to understand work and conclusions? YES → proceed. NO → supplement.
- D2: Significant discussions recorded? YES → proceed. NO → document now.
- D3: Review notes cleared and documented? YES → proceed. NO → clear before sign-off.
- D4: File assembled within 60 days of audit report (SA 230.14)? YES → proceed. NO → expedite assembly.
- D5: Modifications after assembly administrative only? YES → document. NO → substantive modification — document reasons; partner approval.

## Professional Skepticism Probes
- Does documentation genuinely reflect work performed, or are papers prepared retrospectively?
- Are significant judgments documented with reasoning, or just conclusions?
- Are exceptions fully investigated and resolved, or dismissed?
- Are review notes genuinely cleared, or rubber-stamped?
- Are management discussions recorded accurately, or sanitised?

## Considerations
- Documentation enables experienced auditor (not on engagement) to understand work.
- Permanent file: contracts, agreements, master data, organisation chart, prior-year summaries.
- Current file: planning, risk assessment, working papers, conclusions, report, completion memo.
- Tickmarks: legend explaining symbols used in working papers.
- Cross-references: tie numbers across working papers, TB, FS, audit report.

## Common Risks
- Insufficient documentation to support conclusions.
- Significant discussions not recorded.
- Review notes not cleared / rubber-stamped.
- File assembly beyond 60 days.
- Substantive modifications after assembly undocumented.

## Fraud Triggers (SA 240)
- Documentation prepared retrospectively (after audit report).
- Significant judgments documented without reasoning.
- Exceptions dismissed without investigation.
- Review notes cleared without genuine verification.
- Management discussions sanitised in documentation.

## Common Pitfalls
- Working papers without header, preparer / reviewer sign-off, tickmark legend.
- Significant judgments documented as conclusions only.
- Exceptions not investigated and resolved.
- Review notes not cleared before file sign-off.
- File assembly beyond 60 days.

## Validation
- [ ] Audit file structure organised (permanent + current).
- [ ] Each working paper with header, procedure, evidence, conclusion, sign-off, tickmarks.
- [ ] Significant discussions and judgments documented with reasoning.
- [ ] Exceptions logged, investigated, resolved.
- [ ] Review notes cleared and documented; preparer and reviewer signed off.

## Expected Outputs
- Complete audit file (permanent + current).
- Working papers for each audit area with sign-offs.
- Significant discussions and judgments memo.
- Review notes log with clearances.

## Failure Conditions
- Working papers not prepared or incomplete.
- Review notes not cleared.
- Management representation letter not obtained / filed.
- File not assembled within 60 days.

## Escalation Conditions
- Documentation insufficient to support opinion → STOP, supplement documentation, partner consultation.
- Substantive modifications after assembly → STOP, document reasons, partner approval (SA 230).
- Documentation prepared retrospectively (fraud indicator) → STOP, SA 240, partner consultation.
- Review notes unresolved on material matters → STOP, partner consultation before report issuance.
